## Ledger update rule

An item can move to fixed only when all three are recorded: the exact owner/routing fix, a focused automated regression gate, and either SH-0007 practical PASS evidence or an explicit `MANUAL` handoff step with no false readiness claim. A durable commit that the UI reports as failure remains a BLOCKER even when the server later reconciles it correctly.
