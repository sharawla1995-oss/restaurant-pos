# Sharawla POS 10.5.13 — HR Staff Stable Port

This is a source-only semantic port of the isolated Beta/RC1 HR Attendance & Payroll Extension into the Stable 10.5.13 candidate.

## Architecture boundary
- HR reuses Stable `employee_permissions`.
- `has_action_permission_v2(code)` is a narrow compatibility wrapper over Stable `has_permission(code)`.
- No Permissions V2 profile/evaluator stack is imported.
- No Beta loader, POS Offline V2, Point 4, Canonical Stock, licensing, updater, reset or experimental runtime is imported.
- `hr_employees` is the HR person record and remains separate from POS login identity.
- Sharawla Staff is a standalone PWA with its own account/session/device model.

## Backend source order — Beta only
1. `supabase-v10-5-13-hr-foundation.sql`
2. `supabase-v10-5-13-hr-payroll-runtime.sql`
3. `supabase-v10-5-13-hr-ui-support.sql`
4. `supabase-v10-5-13-hr-attendance-extension.sql`
5. Deploy `supabase/functions/hr-staff-api/index.ts`
6. Host `/staff/` over HTTPS.

No SQL, Edge Function or PWA deployment has been performed by this port.

## Admin
Sharawla HR contains Employees, Attendance, Schedules, Leaves/Permissions, Deduction/Bonus Rules, Advances, Adjustments, Payroll, Reports and HR Settings. Staff accounts support temporary PIN, reset, disable/enable, logout-all and device revoke.

## Staff PWA
Employee code/mobile + six-digit PIN, first PIN change, today, check-in/out with live selfie + GPS, offline durable queue/replay, history, schedule, summary, leave request and sync status.

## Acceptance
Before Stable: permission enforcement, branch isolation, employee CRUD, compensation, schedules, geofence, account/PIN/device revoke, live-camera selfie, GPS, offline/restart/replay/ACK-loss, attendance approval/adjustment, leave decision, rules/recurring adjustments, daily/hourly/monthly payroll, payroll-payment idempotency, treasury/advance interaction, and Electron startup/navigation regression.
