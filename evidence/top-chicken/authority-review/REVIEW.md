Enabled modules do not override a commercial denial. The candidate now denies the old cache and requires a fresh server-side Cloud decision for every affected operation. 2. Cloud's existing commercial resolver is used without modification. A new TC-only read-only signed endpoint is proposed in Central. Central's service credential remains in Central; Beta receives only a public Cloud API key and a dedicated TC channel secret. No caller can select another business. This endpoint also needs independent publication approval; it is source only.
3. The Beta executor is service-only. It validates actor, TC scope, required features/modules, freshness and expiry; delegates to the existing permission/branch/financial owners; restores request context; and rolls back all owner changes if permission expires during execution. Direct authenticated calls cannot establish the private transaction context. Replays recheck current authority.
4. The old shared INSERT repair used explicit NULL for other businesses' identity IDs. Beta uses `GENERATED BY DEFAULT` identities, so that changed their behavior. Five non-TC INSERTs now remain exactly the original statements; only TC receives explicit IDs and business identity. The existing singleton belonging to another Beta business is not rebound.
5. A private audited execution gate defaults to false. A pause acquires an update lock after in-flight shared-lock operations complete, preserving all financial records and request receipts.

## Limits

Cloud and Beta are separate databases. Disabling Cloud blocks the next freshly evaluated operation; an already accepted operation has a maximum 10-second decision lifetime. This is not atomic instantaneous revocation across databases. Expiry is checked again after the authoritative write and rolls back the transaction. The private context is bound to transaction/backend/actor and cannot be reused later.

Coverage concerns staff creation/login/password, driver assignment, fulfillment/delivery owners and the shared operational feature evaluator. It is not an assertion that every historic RPC, website intake path or inventory surface has been audited. Intake remains closed. Positive commercial grants in isolation are synthetic; live TC commercial decisions currently deny commerce. No automatic grant was made.
