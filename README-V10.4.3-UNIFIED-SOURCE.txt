TOP BURGER POS V10.4.3 — UNIFIED SOURCE

الهدف
=====
من هذه النسخة فصاعدًا لا يوجد كود كاشير للموبايل وكود آخر للكمبيوتر.
ملفات الواجهة الأساسية الموجودة في جذر المشروع هي المصدر الوحيد:
- index.html
- app.js
- styles.css
- manifest.json
- sw.js

نفس هذه الملفات تعمل على GitHub Pages/PWA، ونفسها تدخل داخل برنامج Windows عند البناء.
ملفات Windows فقط هي main.js و preload.js وإعدادات Electron في package.json.

قاعدة العمل
==========
أي تعديل مشترك في الكاشير يتعمل مرة واحدة في ملفات المصدر الأساسية، ثم:
1) يتم رفع نفس المصدر إلى GitHub.
2) يتم بناء Windows من نفس المصدر بـ npm run dist.
وبذلك لا توجد إعادة كتابة يدوية لنفس الميزة في نسختين.

الحماية من اختلاف رقم النسخة
============================
أضفنا version.json و scripts/check-version.js.
أمر npm run dist يشغل الفحص أولًا، وإذا كان رقم النسخة غير متطابق بين package.json و version.json وواجهة الكاشير يتوقف البناء بدل إخراج نسخة غير متزامنة.
