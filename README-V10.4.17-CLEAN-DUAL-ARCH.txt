Sharawla POS V10.4.17

Packaging-only release based on audited V10.4.16 functionality.
- Builds x64 and ia32 separately.
- Deletes dist between architectures.
- Keeps installers outside dist while switching architectures.
- Prints installer sizes in GitHub Actions.
- Auto-update can detect V10.4.17 as newer than V10.4.16.
