Sharawla POS V10.4.13

Safe layer added on top of V10.4.12:
- Windows EXE only: device-bound Sharawla Cloud activation.
- First activation requires internet and a license generated by Sharawla Admin.
- Device fingerprint is a SHA-256 hash derived from Windows MachineGuid (fallback is local machine data).
- Only the publishable Supabase key is embedded; no service_role/secret key.
- Activation state is stored in the existing local SQLite KV store.
- Offline launch is allowed only within the license offline grace period after a successful online verification.
- Revoked device, inactive license, expired license, or inactive business blocks the next successful online verification.
- Web/PWA POS behavior is unchanged; licensing gate applies to packaged desktop only.
- Top Burger business database, orders, shifts, returns, printing, backup, website flow, and offline queue are untouched.
