- تعديل العملاء وإدارة عناوينهم.
- تعديل/إيقاف المناديب ومناطق الدليفري.
- إضافة/تعديل/إيقاف التصنيفات والأصناف.
- يحافظ على فصل الفروع والطباعة وجلب بيانات العميل.
